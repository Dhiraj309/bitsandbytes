# Quickstart

Welcome to bitsandbytes! This library enables memory-efficient training and
inference through k-bit quantization for PyTorch models.

Quantization reduces GPU memory usage while maintaining comparable model
quality, allowing large language models to run on consumer hardware.

This guide demonstrates how to install bitsandbytes and use 8-bit and 4-bit
quantization in common workflows.

---

## Installation

Install bitsandbytes using pip:

```bash
pip install bitsandbytes
````

**Requirements**

* Python 3.10+
* PyTorch 2.3+
* CUDA-enabled GPU (recommended)

See the [Installation Guide](./installation) for platform-specific instructions.

## 8-bit Inference

Load and run a model using 8-bit quantization with Hugging Face Transformers.

```python
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig

model_id = "meta-llama/Llama-2-7b-hf"

model = AutoModelForCausalLM.from_pretrained(
    model_id,
    device_map="auto",
    quantization_config=BitsAndBytesConfig(load_in_8bit=True),
)

tokenizer = AutoTokenizer.from_pretrained(model_id)

inputs = tokenizer(
    "Hello, my name is",
    return_tensors="pt"
)

outputs = model.generate(**inputs, max_new_tokens=20)

print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

Printing the model architecture will show modules such as
`Linear8bitLt`, confirming that quantized layers are active.

## 4-bit Quantization

For additional memory savings, models can be loaded using 4-bit quantization.

```python
import torch
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_quant_type="nf4",
)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto",
)
```

## QLoRA Fine-tuning

Combine 4-bit quantization with LoRA adapters for efficient fine-tuning.

```python
from transformers import AutoModelForCausalLM, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model, prepare_model_for_kbit_training

bnb_config = BitsAndBytesConfig(load_in_4bit=True)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-hf",
    quantization_config=bnb_config,
    device_map="auto",
)

model = prepare_model_for_kbit_training(model)

lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    task_type="CAUSAL_LM",
)

model = get_peft_model(model, lora_config)
```

## 8-bit Optimizers

bitsandbytes provides memory-efficient optimizer implementations that
store optimizer states in 8-bit precision.

```python
import torch
import bitsandbytes as bnb

model = torch.nn.Linear(128, 2)

optimizer = bnb.optim.Adam8bit(
    model.parameters(),
    lr=1e-3,
)

x = torch.randn(16, 128)
y = torch.randint(0, 2, (16,))

criterion = torch.nn.CrossEntropyLoss()

optimizer.zero_grad()
loss = criterion(model(x), y)
loss.backward()
optimizer.step()

print(type(optimizer))
```

The optimizer type should report:

```
bitsandbytes.optim.adam.Adam8bit
```

## Quantized Layers

Quantized modules can be used directly as drop-in replacements for
standard PyTorch layers.

```python
import torch
import bitsandbytes as bnb

linear_8bit = bnb.nn.Linear8bitLt(1024, 1024)

linear_4bit = bnb.nn.Linear4bit(
    1024,
    1024,
    compute_dtype=torch.bfloat16,
)
```
